# Code of Conduct

## Our standards

This project aims to be a respectful, technically focused, and welcoming open-source space.

Examples of behavior that contribute to a positive environment include:

- being respectful and patient
- giving constructive technical feedback
- assuming good intent while still discussing problems honestly
- focusing on reproducible facts, logs, and code when reporting issues
- accepting that maintainers and contributors may have different experience levels and backgrounds

Examples of unacceptable behavior include:

- harassment, threats, or intimidation
- hateful, discriminatory, or demeaning language
- personal attacks, dogpiling, or repeated bad-faith arguments
- doxxing or sharing private information without consent
- spam, trolling, or deliberately disruptive behavior
- publishing exploit details irresponsibly when a private report would be safer

## Scope

This Code of Conduct applies to:

- the repository
- issues
- pull requests
- discussions
- review comments
- other project-managed communication spaces

## Enforcement

Project maintainers may take any action they consider appropriate, including:

- editing or removing comments
- locking conversations
- rejecting contributions
- temporarily or permanently blocking participation

## Reporting

If you experience or witness unacceptable behavior:

1. Use GitHub moderation and reporting tools when appropriate.
2. Contact the maintainer through the available repository or GitHub profile contact channel.
3. Share only the information needed to investigate the problem.

Reports will be handled as respectfully and privately as practical.

## Maintainer expectations

Maintainers are expected to:

- apply rules consistently
- prioritize community safety over winning arguments
- keep moderation actions proportionate
- separate technical disagreement from personal attacks

## Project culture

This repository values:

- careful bug reports
- reproducible examples
- honest documentation
- respectful disagreement
- maintainable code over unnecessary cleverness
